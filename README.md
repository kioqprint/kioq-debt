# ديوني — تطبيق Android

تطبيق عربي بسيط لإدارة الديون وفق ترتيب الأولويات الذي يحدده المستخدم، اعتماداً على الدخل والمصاريف الفعلية.

## القواعد
- كل دخل إضافي يُسجل فوراً مهما كان مصدره.
- المصاريف تخصم من الأموال المتاحة.
- المستخدم يحدد مبلغ الدفعة؛ لا توجد دفعات إلزامية.
- السداد يذهب إلى أول دين غير مكتمل حسب القائمة.
- عند إكمال الدين ينتقل التطبيق إلى الدين التالي.
- دين الحانوت مضاف بقيمة غير محددة ويحتاج إدخالها لاحقاً.

## بيانات البداية
السكنة 192,000 دج (15 جانفي 2027)، ياسين 146,000، رضا 150,000، شريفي 400,000، الحانوت (23 أوت 2027، المبلغ غير محدد)، سفيان 30,000، أبي 15,000، العرصة 6,000، فتحي 10,000، معمر 5,000، مصطفى 130,000، العيد 30,000، نصر الدين 10,000، أمينة 70,000، الحاج 80,000، كمال 1,110، فريد 1,000.

## البناء
افتح المشروع في Android Studio، ثم Gradle Sync وتشغيل على جهاز Android أو Emulator.

هذه بداية MVP؛ نحتاج لاحقاً اختبار البناء، إدخال قيمة الحانوت، تعديل الديون، ونسخ احتياطي.
